# SAEF delayed open release (additional permission)

Granted by Guillermo Llopis-Garcia (SOMA AI, somaai.earth) on 2026-11-26.

This is an additional permission for every release of the SOMA AI Emission Factors (SAEF) dataset published under the SOMA AI Emission Factors Data Licence 1.0 (Non-Commercial), from version 3.3.0 onward.

1. **Six months after publication, each release is also CC BY 4.0.** Six months after a release is first published, the data files of that release are also licensed under the Creative Commons Attribution 4.0 International licence (CC BY 4.0, https://creativecommons.org/licenses/by/4.0/), for any use, including commercial use. Attribution follows section 4 of the data licence, with "Licensed under CC BY 4.0" in place of the licence name.
2. **Publication date.** The publication date of a release is the publication date of its Zenodo record.
3. **No withdrawal.** This permission will not be withdrawn for any release once that release is published.
4. **Scope.** It covers only the released data files of each release once its date has passed. It does not cover later releases before their own date, the SOMA API, the SOMA MCP server, other SOMA services, or the SOMA code tools (PolyForm Noncommercial 1.0.0).
5. **Before the date.** Until its six-month date, a release stays under the SOMA AI Emission Factors Data Licence 1.0 (Non-Commercial) only. Commercial use before that date needs a commercial licence (https://somaai.earth/licensing).
